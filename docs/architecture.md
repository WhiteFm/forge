# Архитектура Forge

Forge — автономное React-приложение без серверного состояния.

```text
визуальные формы
  → ForgeProject в localStorage
  → проверка идентификаторов, формул, ссылок и обязательных полей
  → канонический Content Pack JSON
  → Character Creation List / будущий VTT
```

## Принципы

- стабильные ID отделены от названий и описаний;
- русская и английская локализации равноправны;
- официальные данные создаются теми же формами, что и homebrew;
- каждый числовой бонус или владение задаётся атомарным эффектом;
- ограниченное умение обязательно описывает ресурс и восстановление;
- класс хранит отдельные владения при старте и мультиклассировании;
- ошибки блокируют экспорт, предупреждения требуют проверки автора;
- проект и готовый контент-пакет экспортируются разными файлами.
