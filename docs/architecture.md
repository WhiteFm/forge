# Архитектурные границы Forge

Forge — самостоятельное mobile-first веб-приложение и отдельный Git-репозиторий.

## Локальные данные

- IndexedDB для автоматического кэша и черновиков;
- JSON для переносимого рабочего проекта;
- `.wsgpack` для опубликованного набора контента;
- ресурсы пакета хранятся внутри его архива.

## Контент

- технические значения не зависят от перевода;
- RU/EN и следующие языки используют стабильный ID сущности;
- формулы проходят безопасный парсер Character;
- официальные namespace доступны только административной публикации;
- homebrew не может переопределить официальный ID.

## Интеграция

Версия Forge фиксирует совместимую версию контент-контракта. Обновление контракта выполняется отдельной миграцией и никогда не меняет опубликованные пакеты задним числом.
