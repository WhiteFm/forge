# Сущности и поля Forge

## 1. Общие правила

Любая сущность имеет общую основу:

| Поле | Назначение |
|---|---|
| `id` | автоматический уникальный технический ID |
| `entityType` | тип сущности |
| `status` | `draft`, `review`, `published` или `deprecated` |
| `localization.en.name` | английское имя; участвует в создании ID |
| `localization.en.description` | английское описание |
| `localization.ru.name` | русское имя |
| `localization.ru.description` | русское описание |

Описание не является правилом. Любая рассчитываемая механика должна быть записана в структурированных полях.

## 2. Class / Класс

Класс определяет базовые параметры, правила мультиклассирования, прогрессию 1–20, выдаваемые умения, выборы и стартовое снаряжение.

### Ядро класса

| Поле | Значения | Назначение |
|---|---|---|
| `hitDie` | `d6`, `d8`, `d10`, `d12` | кость хитов класса |
| `primaryAbilities` | `str`, `dex`, `con`, `int`, `wis`, `cha` | основные характеристики |
| `multiclassPrerequisite` | условное выражение | проверка перед добавлением уровня класса |
| `startingHpFormula` | арифметическое выражение | ХП на первом уровне класса |
| `levelUpHpFormula` | арифметическое выражение | фиксированное увеличение ХП на следующем уровне |
| `startingProficiencies` | список ID | владения при взятии класса первым |
| `multiclassProficiencies` | список ID | владения при добавлении класса через мультикласс |
| `spellcastingAbility` | характеристика или пусто | базовая характеристика заклинателя |
| `casterProgression` | см. ниже | вклад класса в общий уровень заклинателя |
| `casterLevelFormula` | выражение | явная формула уровня заклинателя |

`casterProgression`:

- `none` — класс не даёт стандартной прогрессии ячеек;
- `full` — полный заклинатель;
- `half_down` — половина уровня с округлением вниз;
- `half_up` — половина уровня с округлением вверх;
- `third` — треть уровня;
- `pact` — отдельная пактовая прогрессия;
- `custom` — потребитель использует `casterLevelFormula` или собственную таблицу.

Если прогрессия не `none`, обязательно выбрать `spellcastingAbility`.

### Прогрессия уровней

`levels[]` содержит последовательные записи:

```json
{
  "level": 3,
  "featureIds": ["srd52.feature.wizard_subclass"]
}
```

- уровни всегда начинаются с 1 и идут без пропусков;
- номер меняется только добавлением или удалением уровня;
- `featureIds` — умения, выдаваемые на этом уровне;
- одинаковое умение не следует выдавать повторно без игрового основания.

### Таблица класса

`classProgression[]` содержит одну строку на каждый уровень:

| Поле | Назначение |
|---|---|
| `level` | защищённый номер уровня |
| `proficiencyBonus` | бонус мастерства |
| `cantripsKnown` | количество известных заговоров |
| `preparedSpells` | количество подготовленных заклинаний |
| `spellSlots[0..8]` | число ячеек 1–9 уровней |

Даже незаклинательный класс хранит массив из девяти нулей.

### Выборы и снаряжение

`choices[]` описывает решения игрока, например выбор навыков. `equipmentOptions[]` описывает альтернативные стартовые комплекты, фиксированные предметы, предметы из предыдущего выбора и медные монеты.

## 3. Subclass / Подкласс

| Поле | Назначение |
|---|---|
| `classId` | обязательная ссылка на базовый класс |
| `subclassLevels[]` | уровни, на которых подкласс выдаёт умения |

В отличие от класса, уровни подкласса можно вводить вручную. Например, подкласс может выдавать умения только на 3, 6, 10 и 14 уровнях.

Подклассы отображаются в списке внутри раскрывающейся группы базового класса. Подкласс без корректного `classId` попадает в группу «Без класса» и получает ошибку валидации.

## 4. Species / Вид

| Поле | Диапазон/значения | Назначение |
|---|---|---|
| `lifespanYears` | 0–1000 | типичная продолжительность жизни |
| `sizeOptions` | `tiny`…`gargantuan` | допустимые размеры |
| `baseSpeeds.walk` | 0–120 ft | скорость ходьбы |
| `baseSpeeds.fly` | 0–120 ft | скорость полёта |
| `baseSpeeds.swim` | 0–120 ft | скорость плавания |
| `senses.vision` | 0–1000 ft | дальность обычного зрения; 0 означает отсутствие отдельного числового значения |
| `senses.darkvision` | 0–1000 ft | темнозрение; 0 — нет |
| `senses.blindsight` | 0–1000 ft | слепое зрение; 0 — нет |
| `featureIds` | ссылки на умения | фиксированные умения вида |
| `choices` | выборы | происхождение, наследие, вариант размера и другие решения |

Сопротивления, иммунитеты, владения и прочая математика вида обычно задаются через связанные умения и их эффекты.

## 5. Background / Предыстория

### Характеристики

| Поле | Назначение |
|---|---|
| `abilityOptions` | ровно три характеристики, доступные предыстории |
| `abilityScoreIncrease.allowedAbilities` | техническая копия разрешённых характеристик |
| `abilityScoreIncrease.distributions` | варианты распределения бонусов |
| `abilityScoreIncrease.maximumScore` | максимальное значение после повышения |

Подготовленные схемы:

- `[[2,1],[1,1,1]]` — игрок выбирает `+2/+1` или `+1/+1/+1`;
- `[[2,1]]` — только `+2/+1`;
- `[[1,1,1]]` — только `+1/+1/+1`.

### Слоты наград

| Поле | Содержимое |
|---|---|
| `featIds` | черты |
| `skillProficiencySlots` | владения навыками |
| `toolProficiencySlots` | владения инструментами |
| `backgroundFeatureSlots` | умения |

Можно создать несколько слотов каждого типа. Заполненный слот выдаёт конкретную сущность. Пустой сохранённый слот означает, что игрок выберет значение позже. Именно редакторы слотов предыстории поддерживают это поведение явно.

`featChoiceSelections[]` хранит заранее выбранные варианты внутри выдаваемой черты:

```json
{
  "choiceId": "srd52.feat.example.choice_1",
  "optionIds": ["srd52.feature.example_option"]
}
```

### Комплекты снаряжения

Каждый `equipmentOptions[]` содержит:

- автоматический `id`;
- локализованные `name` и `nameRu`;
- `items[]` — фиксированные предметы и количество;
- `choiceItems[]` — предметы, взятые из результата одного из выборов сущности;
- `currencyCp` — деньги от 0 до 999999 cp.

Название комплекта можно изменить прямо в его заголовке. ID перестроится из английского имени.

## 6. Feat / Черта

| Поле | Назначение |
|---|---|
| `featCategory` | `origin`, `general`, `fighting_style`, `epic_boon`, `custom` |
| `repeatable` | можно ли выбрать черту повторно |
| `repeatConstraint` | текстовая/техническая метка дополнительного ограничения повторов |
| `prerequisites[]` | условия получения |
| `prerequisiteExpressions[]` | структурированные версии условий |
| `featureIds[]` | связанные умения, реализующие механику черты |
| `choices[]` | решения игрока внутри черты |

Кнопка удаления выбора удаляет и связанное применение этого выбора, чтобы в паке не оставалась ссылка на отсутствующий Choice ID.

## 7. Feature / Умение

Умение — основной контейнер механики. Класс, вид, предыстория или черта обычно выдают умение, а умение содержит эффекты, ресурс и выдаваемые заклинания.

### Тип умения

| `mode` | Назначение |
|---|---|
| `always_on` | одноразово/постоянно влияет на итоговые параметры и всегда учитывается |
| `manual_unlimited` | пассивное в терминологии проекта: применение объявляется, ресурс не ограничен |
| `limited_use` | активное умение с ограниченными применениями |

### Активация

`none`, `action`, `bonus_action`, `reaction`, `free_action`, `special`.

### Ресурс ограниченного умения

При `limited_use` обязательно задаётся:

| Поле | Назначение |
|---|---|
| `resource.id` | автоматический ID ресурса |
| `maximumFormula` | максимум применений |
| `maximumExpression` | структурированная формула максимума |
| `recovery` | событие восстановления |
| `recoveryFormula` | сколько единиц восстановить |
| `recoveryExpression` | структурированная формула восстановления |

### Дарованные заклинания

`spellGrants[]` позволяет выдать заклинание умением:

| Поле | Назначение |
|---|---|
| `spellId` | ссылка на заклинание этого пака |
| `atCharacterLevel` | минимальный уровень персонажа |
| `alwaysPrepared` | всегда подготовлено |
| `freeUsesFormula` | бесплатные применения |
| `recovery` | восстановление бесплатных применений |
| `allowSpellSlots` | можно ли также тратить обычные ячейки |
| `spellcastingAbilityOptions` | допустимые характеристики заклинателя |

Математика умения задаётся в `effects[]`; решения игрока — в `choices[]`.

## 8. Item / Предмет

### Общие параметры

| Поле | Назначение |
|---|---|
| `itemType` | тип предмета |
| `weightLb` | вес в фунтах, неотрицательный |
| `costCp` | стоимость 0–999999 cp |
| `stackable` | можно объединять одинаковые экземпляры в стек |
| `consumable` | расходуется при применении |
| `requiresAttunement` | требует настройки |
| `equipmentSlots[]` | слоты экипировки |
| `requirements[]` | условия использования |
| `spellcastingFocusFor[]` | классы, для которых предмет является фокусировкой |
| `containedItems[]` | предметы внутри контейнера и их количество |
| `effects[]` | эффекты экипировки, настройки или применения |

### Оружие

При выборе `itemType: weapon` создаётся `weaponProfile`:

| Поле | Значения/назначение |
|---|---|
| `category` | `simple_melee`, `simple_ranged`, `martial_melee`, `martial_ranged`, `custom` |
| `damage` | формула вида `1d8 + 1` |
| `damageTypeId` | тип урона, например `damage.slashing` |
| `scalingAbility` | `str`, `dex`, `finesse`, `custom` |
| `rangeNormalFeet` | нормальная дистанция |
| `rangeLongFeet` | максимальная дистанция |
| `propertyIds[]` | свойства оружия |
| `masteryId` | `mastery.cleave`, `graze`, `nick`, `push`, `sap`, `slow`, `topple` или `vex` |

### Доспех и щит

`armorProfile`:

| Поле | Назначение |
|---|---|
| `category` | `light`, `medium`, `heavy`, `shield`, `custom` |
| `baseAc` | базовый КД |
| `addsDexterity` | прибавлять модификатор Ловкости |
| `maxDexterityBonus` | предел бонуса Ловкости |
| `strengthRequirement` | требуемая Сила; 0 — нет требования |
| `stealthDisadvantage` | помеха к Скрытности |

### Заряды

`charges` включается отдельным переключателем и содержит:

- `maximumFormula` и структурированное выражение;
- `recovery`: `short_rest`, `long_rest`, `both`, `dawn`, `manual`, `never`.

### Материальные компоненты

Материальный компонент — обычная сущность `item`, чаще всего с `itemType: spell_material`. Это позволяет CCL хранить его в инвентаре, учитывать количество, стоимость и расходование.

`materialProfile` — расширенные данные импортированного компонента: исходное название, встреченные стоимости и список использующих его заклинаний. В текущем интерфейсе отдельной формы для этого профиля нет, но данные сохраняются при импорте и экспорте.

## 9. Spell / Заклинание

### Основные параметры

| Поле | Значения/назначение |
|---|---|
| `spellLevel` | 0–9; 0 — заговор |
| `schoolId` | школа магии |
| `spellClassIds[]` | классы, в списках которых есть заклинание |
| `casting.actionType` | `action`, `bonus_action`, `reaction`, `minute`, `hour`, `special` |
| `casting.value` | число единиц времени |
| `casting.reactionTrigger` | условие реакции |

Импортированные данные могут дополнительно хранить `casting.raw` — исходную текстовую запись времени.

### Дальность и область

`range.type`:

- `self` — на себя;
- `touch` — касание;
- `distance` — числовая дистанция;
- `sight` — в пределах видимости;
- `unlimited` — неограниченно;
- `special` — особая дальность.

При `distance` используется `distanceFeet`. Импортированные записи также могут сохранять исходные `distanceValue`, `distanceUnit` и `raw`.

Основная область `area`:

- `none`, `cone`, `cube`, `cylinder`, `emanation`, `line`, `sphere`, `wall`;
- `sizeFeet` — основной размер в футах.

`areas[]` — расширенный импортированный список нескольких областей и измерений. Он сохраняет `rawShape`, `rawSize` и `dimensionsFeet[]`, даже если простая форма редактирует только основную `area`.

### Длительность

`duration.type`: `instant`, `rounds`, `minutes`, `hours`, `days`, `until_dispelled`, `special`.

- `value` используется для числовой длительности;
- `concentration` отмечает концентрацию;
- `raw` может сохранять исходный импортированный текст.

### Компоненты

| Поле | Назначение |
|---|---|
| `verbal` | V-компонент |
| `somatic` | S-компонент |
| `material` | M-компонент |
| `materialText` | исходное описание материала |
| `materialCostCp` | общая стоимость в cp |
| `materialConsumed` | материал расходуется |

Если есть текст материального компонента, должен существовать хотя бы один `materialGroups[]` с предметами инвентаря.

Группа материалов содержит:

- автоматический ID и локализованное имя;
- `sourceText` — исходную формулировку;
- `minimumTotalCostCp` — минимальную общую стоимость;
- `sourceCurrency` — исходное обозначение валюты;
- `consumed` — расходуется ли группа;
- `entries[]` — ссылки на предметы, количество, минимальная стоимость и расходование каждого элемента.

### Бросок, спасбросок и ритуал

| Поле | Значения |
|---|---|
| `ritual` | да/нет |
| `attackType` | `none`, `melee_spell`, `ranged_spell` |
| `savingThrowAbility` | характеристика или пусто |
| `automationLevel` | `full`, `partial`, `manual` |

### Механические профили

`spellProfiles[]` описывает урон, лечение или нейтральный периодический эффект:

- `category`: `damage`, `healing`, `neutral`;
- начальное количество и тип костей;
- периодическое количество и тип костей;
- период в раундах;
- `higherLevel.enabled` — масштабирование при повышении уровня.

Поля `sourceSheet` и `sourceRow` сохраняют техническое происхождение строки при табличном импорте. Они не являются лицензией сущности.

### Масштабирование

`scaling[]`:

| Поле | Назначение |
|---|---|
| `type` | `character_level`, `spell_slot_level`, `class_level` |
| `at` | пороговый уровень |
| `value` | новое значение или добавка, например `1d6` |

Сложную фактическую механику заклинания следует дополнительно описывать атомарными `effects[]`.

## 10. Reference / Справочник

Справочник создаёт стабильное переиспользуемое значение.

`referenceCategory`:

- `ability` — характеристика;
- `skill` — навык;
- `language` — язык;
- `tool` — инструмент;
- `damage_type` — тип урона;
- `condition` — состояние;
- `sense` — чувство;
- `movement_type` — вид движения;
- `size` — размер;
- `rest_type` — отдых;
- `action_type` — тип действия;
- `weapon_property` — свойство оружия;
- `weapon_mastery` — мастерство оружия;
- `armor_training` — владение доспехами;
- `spell_school` — школа магии.

`referenceValue` — набор дополнительных свойств. Редактор поддерживает строки, числа, булевы значения и списки. Новое свойство добавляется по имени. Например, навык может хранить связанную характеристику и порядок сортировки.

## 11. Поля, сохраняемые без отдельной формы

Часть расширенных данных может поступить из мигратора или генератора SRD и сохраняется в `.forge.json`, хотя текущий интерфейс не даёт отдельной формы для каждого вложенного свойства:

- `materialProfile` предмета;
- расширенные `areas[]`, `raw` и исходные единицы заклинания;
- `spellCategories[]`;
- `featChoiceSelections[]` предыстории;
- атрибуция и язык по умолчанию в настройках пака.

Не удаляйте такие поля ручным «упрощением» JSON: они нужны для переносимости и будущей автоматизации.
