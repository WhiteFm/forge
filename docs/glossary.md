# Словарь обозначений Forge

## Игровые сокращения

| Обозначение | Значение |
|---|---|
| `LVL` / `УР.` | уровень класса, персонажа, заклинания или ячейки — определяется контекстом |
| `PB` / `БМ` | Proficiency Bonus / бонус мастерства |
| `HP` / `ХП` | Hit Points / хиты |
| `AC` / `КД` | Armor Class / класс доспеха |
| `DC` / `СЛ` | Difficulty Class / сложность проверки или спасброска |
| `STR` / `СИЛ` | Strength / Сила (`str`) |
| `DEX` / `ЛОВ` | Dexterity / Ловкость (`dex`) |
| `CON` / `ТЕЛ` | Constitution / Телосложение (`con`) |
| `INT` / `ИНТ` | Intelligence / Интеллект (`int`) |
| `WIS` / `МДР` | Wisdom / Мудрость (`wis`) |
| `CHA` / `ХАР` | Charisma / Харизма (`cha`) |
| `V` | verbal — вербальный компонент |
| `S` | somatic — соматический компонент |
| `M` | material — материальный компонент |

## Единицы

| Обозначение | Значение |
|---|---|
| `cp` / `мм` | copper pieces / медные монеты; базовая денежная единица Forge |
| `lb` | фунты веса |
| `ft` | футы расстояния |
| `square` | клетка виртуального или физического поля |
| `d4`, `d6`, `d8`, `d10`, `d12`, `d20`, `d100` | тип игральной кости |
| `2d6 + 3` | бросить две кости d6 и прибавить 3 |

Все денежные значения в технической модели хранятся в `cp`, чтобы не использовать дроби. Максимум одного денежного поля интерфейса — `999999 cp`.

## Названия файлов и систем

| Термин | Значение |
|---|---|
| Forge / Кузница | редактор контент-паков |
| CCL | Character Creation List — приложение создания и управления персонажами |
| VTT | Virtual Tabletop — будущий виртуальный игровой стол |
| SRD | System Reference Document — открытая часть правил |
| JSON | текстовый формат структурированных данных |
| `.forge.json` | редактируемый проект Forge |
| `.wsgpack` | канонический переносимый пакет для CCL/VTT |
| TSV | табличный текст с разделением колонок табуляцией; используется при копировании из Excel |
| schemaVersion | версия структуры данных Forge |
| SemVer | формат версии `MAJOR.MINOR.PATCH`, например `1.4.2` |

## ID и ссылки

| Термин | Значение |
|---|---|
| Pack ID | общий машинный префикс пака |
| Entity ID | уникальный ID сущности, например `srd52.class.wizard` |
| Subentity ID | ID вложенной записи, например выбора или эффекта |
| reference / ссылка | сохранённый ID другой сущности вместо копии её данных |
| namespace | пространство имён; в `.wsgpack` вычисляется из Pack ID |
| slug | нормализованная часть ID из английского названия |

Пустой слот ссылки означает «значение выберет игрок позже», только если конкретный редактор явно показывает такую подпись. Обычная пустая ссылка чаще означает незаполненное поле.

## Локализация

| Обозначение | Значение |
|---|---|
| `_en` | английское название или описание |
| `_ru` | русское название или описание |
| `defaultLocale` | язык по умолчанию в итоговом паке; сейчас `en` |
| localization | текст, предназначенный для человека и не участвующий в расчётах |

## Статусы

| Значение | Значение в работе |
|---|---|
| `draft` | черновик |
| `review` | на проверке |
| `published` | опубликовано и должно сохранять совместимые ID |
| `deprecated` | устарело, но сохранено ради старых ссылок |

## Уровни автоматизации

| Значение | Смысл |
|---|---|
| `full` | потребляющее приложение может применить механику автоматически |
| `partial` | часть механики автоматизирована, часть требует решения игрока или ведущего |
| `manual` | данные сохранены структурно, но применение требует ручного действия |

Уровень автоматизации — обещание потребителю данных, а не отдельный алгоритм внутри Forge.

## Режимы умений и эффектов

| Значение | Смысл |
|---|---|
| `always_on` | эффект действует постоянно и участвует в математике всегда |
| `manual_unlimited` | игрок объявляет применение, число применений не ограничено ресурсом |
| `limited_use` | применение расходует ограниченный ресурс |
| `equipped` | эффект действует, пока предмет экипирован |
| `attuned` | эффект действует при настройке на предмет |
| `on_event` | эффект запускается указанным событием |

## Типы ссылочных справочников

`ability`, `skill`, `language`, `tool`, `damage_type`, `condition`, `sense`, `movement_type`, `size`, `rest_type`, `action_type`, `weapon_property`, `weapon_mastery`, `armor_training`, `spell_school`.

Справочник нужен, когда одно стабильное техническое значение используется множеством сущностей и должно иметь локализованное название и дополнительные свойства.
