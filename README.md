# WSGuild Forge / Кузница

Отдельное веб-приложение для визуального создания официального и homebrew-контента D&D 5.5e.

## Назначение

Кузница позволит создавать без Excel:

- классы и подклассы;
- виды персонажей;
- предыстории;
- черты и умения;
- предметы;
- заклинания;
- справочники и локализации.

Рабочие проекты сохраняются локально, экспортируются в канонический JSON и упаковываются в переносимый файл `.wsgpack`. Русский, английский и будущие языки являются равноправными локализациями контента.

## Связь с Character

Репозиторий Character хранит опубликованный контракт контента: JSON Schema, стабильные ID, безопасные формулы и правила расчёта. Кузница будет подключать этот контракт как версионированную зависимость, а не копировать схемы вручную.

```text
Forge → canonical JSON / .wsgpack → Character → future VTT
```

## Текущий статус

Репозиторий отделён и готов к самостоятельной разработке. Реализация интерфейса начнётся после отдельного согласования экранов и сценариев редактора.
